# GölgeFilo

Büyükşehirlerde boş dönüş yapan ticari araçların kapasitesini işletmelerle buluşturan lojistik platformu. Bu sürüm, tarayıcıda çalışan tek dosyalık arayüz prototipidir.

## Sürüm
**version1** – Giriş/üyelik, işletme abonelik paketleri, şoför ve işletme panelleri, araç uyumluluk simülasyonu, gizlilik merkezi.

## Çalıştırma
`index.html` dosyasını tarayıcıda açın.
